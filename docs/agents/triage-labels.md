# Labels de triage

Les skills utilisent cinq rôles canoniques de triage. Ce fichier les mappe aux chaînes réelles utilisées dans ce repo.

| Rôle dans mattpocock/skills | Label dans notre tracker | Signification                                      |
| --------------------------- | ------------------------ | -------------------------------------------------- |
| `needs-triage`              | `à-trier`                | Un mainteneur doit évaluer cette issue             |
| `needs-info`                | `info-manquante`         | En attente d'informations supplémentaires          |
| `ready-for-agent`           | `prêt-agent`             | Entièrement spécifié, prêt pour un agent AFK       |
| `ready-for-human`           | `prêt-humain`            | Nécessite une implémentation humaine               |
| `wontfix`                   | `annulé`                 | Ne sera pas traité                                 |

Quand un skill mentionne un rôle (ex: "appliquer le label AFK-ready"), utiliser la chaîne correspondante de la colonne droite.
